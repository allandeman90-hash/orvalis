# ORVALIS — PÉRIMÈTRE DE SORTIE ET PLAFOND LONG TERME

Status: **CANON DESIGN OVERRIDE — 2026-10-09**

Ce document corrige toute formulation antérieure laissant entendre que le niveau 50 serait le plafond définitif d'Orvalis ou que les extensions futures doivent être conçues maintenant.

En cas de conflit avec `CAMPAIGN_00_SCOPE_LEVEL_50.md`, `CAMPAIGN_01_LEVELING_1_30.md`, `CAMPAIGN_02_QUEST_AUDIT.md` ou `CAMPAIGN_02B_EXPANDED_CONTENT_1_50.md`, le présent document fait foi pour le périmètre de sortie et la progression à long terme.

---

# I. JEU DE BASE AU LANCEMENT

Le jeu de base visé pour la première sortie complète d'Orvalis couvre :

# **NIVEAUX 1 À 50**

Le niveau 50 est donc :

- le niveau maximum **au lancement** ;
- le plafond de progression de personnage de la version de base ;
- le point où commence l'endgame du jeu de base.

Il n'est PAS le plafond définitif de toute la vie d'Orvalis.

Tout le contenu actuellement conçu pour les niveaux 1–50 — y compris les nouvelles zones, quêtes, donjons, raids et cartes nécessaires pour rendre ce parcours digne d'un vrai MMORPG — appartient au **jeu de base**, pas à une première ou deuxième extension.

Les termes `Arc I`, `Arc II` et `Arc III` désignent donc des **actes narratifs internes au jeu de base 1–50**, et non des extensions commerciales ou post-lancement.

---

# II. PLAFOND LONG TERME

L'objectif à long terme d'Orvalis est un niveau de personnage maximal définitif de :

# **100**

Ce plafond doit être atteint plus tard au cours de la vie du jeu, au moyen de futures extensions ou grandes mises à jour de contenu.

Aucune cadence précise n'est canonisée aujourd'hui.

Il n'est donc pas décidé que chaque extension ajoutera exactement 10 niveaux, ni combien d'extensions seront nécessaires.

Seul le principe suivant est verrouillé :

> **Orvalis sort avec un plafond de niveau 50 et pourra progressivement relever ce plafond jusqu'à un maximum définitif de niveau 100.**

---

# III. CE QU'ON NE CONÇOIT PAS MAINTENANT

Le jeu n'est pas encore sorti.

Par conséquent, il est interdit de détourner la conception actuelle vers des extensions post-lancement détaillées.

Pour les niveaux 51–100, on ne doit PAS encore définir en détail :

- les nouvelles cartes ;
- les nouvelles capitales ;
- les nouveaux continents ;
- les nouveaux raids ;
- les campagnes complètes ;
- les boss finaux ;
- les révélations majeures réservées aux extensions ;
- les nouvelles civilisations complètes ;
- les progressions d'équipement précises.

On peut seulement conserver des **mystères, portes narratives et espaces géographiques ouverts** afin que les futures extensions aient de la place pour exister.

Le travail actif reste concentré sur la qualité et la complétude du **jeu de base 1–50**.

---

# IV. RUNES ET NIVEAU DE PERSONNAGE

Le niveau de personnage et la progression runique restent deux choses différentes.

Au lancement :

- niveau personnage maximum = **50** ;
- niveau runique = **sans plafond connu**.

À très long terme :

- niveau personnage maximum définitif = **100** ;
- niveau runique = **toujours sans plafond connu**.

Ainsi, même deux personnages niveau 100 de même classe et équipés de façon comparable peuvent devenir incomparablement différents en puissance grâce à leur Ascendance runique.

Le fantasme central d'Orvalis ne dépend donc jamais uniquement du niveau de personnage.

---

# V. CONSÉQUENCE POUR LE CONTENU 1–50

Le fait qu'Orvalis puisse un jour atteindre le niveau 100 ne doit PAS servir d'excuse pour rendre le jeu de base 1–50 incomplet.

La version de lancement doit déjà posséder :

- une campagne complète avec une vraie conclusion de jeu de base ;
- suffisamment de zones et de cartes ;
- une densité de quêtes digne d'un MMORPG ;
- les Huit Ordres pleinement représentés ;
- les factions et peuples suffisamment développés ;
- plusieurs donjons ;
- plusieurs raids/endgame encounters ;
- professions, exploration, PvP facultatif, boss de monde et activités secondaires ;
- un endgame niveau 50 soutenu notamment par la progression runique et l'Abîme sans fin.

Le joueur doit pouvoir terminer le jeu de base et avoir le sentiment d'avoir vécu une aventure complète, même si des mystères plus vastes restent ouverts pour l'avenir.

---

# VI. CONSÉQUENCE POUR LES DOCUMENTS EXISTANTS

`CAMPAIGN_02B_EXPANDED_CONTENT_1_50.md` reste un blueprint du **jeu de base**.

Ses régions et contenus 30–50 ne doivent plus être décrits ou interprétés comme des extensions.

Toute phrase affirmant que le niveau 50 est la fin définitive de la progression de personnage est obsolète.

La formulation correcte est désormais :

> **Niveau 50 = plafond de lancement. Niveau 100 = plafond définitif visé à long terme. Progression runique = sans plafond connu.**

---

# VII. PRIORITÉ DE PRODUCTION

Ordre de travail actuel :

1. terminer le contenu et le lore du jeu de base 1–50 ;
2. verrouiller la carte et les systèmes nécessaires à cette sortie ;
3. produire/intégrer les assets et rendre le jeu jouable de bout en bout ;
4. stabiliser, tester et sortir Orvalis ;
5. seulement après cela, concevoir en profondeur les extensions menant progressivement vers le niveau 100.

Le projet ne doit plus sauter en conception détaillée d'extensions pendant que le jeu de base n'est pas encore terminé.
